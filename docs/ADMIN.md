# 管理员查看使用记录

本版本提供 Windows 原生管理窗口，样式参考 OnlineSystem 操作记录页面。数据来自本机 SQLite 和配置中的录像目录，无需启动服务器，也没有远程网页管理地址。

## 打开

### 自定义本地管理员（用户名和密码）

支持独立于校园认证的本地管理员。在 Windows 管理员账户运行 `scripts/Set-LocalAdministrator.ps1`，通过设置窗口保存自定义用户名和密码。重新登录打印账户后，在原登录页勾选“本地管理员登录”。首次配置、旧版更新和密码重设见 [LOCAL-ADMIN.md](LOCAL-ADMIN.md)。默认没有本地管理员，不需要向开发者提供密码。

### 从打印登录页进入（校园管理员账号）

由部署管理员修改受保护安装目录中的 `appsettings.json`，把允许进入管理页的真实校园学号填入名单：

```json
"AdministratorStudentIds": ["管理员的真实学号", "另一管理员的真实学号"]
```

此处为格式示例，不是可用账号。默认名单为空，不提供默认管理密码。保存配置后，注销并重新登录专用 Windows 账户，让配置生效。

在原登录页输入名单内账号的校园账号密码，组织可留空。校园接口认证成功且返回学号与名单精确匹配后，直接进入记录页面，不打开 Studio、不产生打印使用次数、不录制管理员查看过程。普通账号仍需填写组织后进入打印软件。权限不依据姓名、组织或未经认证的输入账号。

点击“退出管理页面”、鼠标连续达到 IdleSeconds（默认 300 秒）不移动，或 Windows 会话锁定/断开，会关闭管理窗口及其子窗口，回到认证页。保留的打印工程不因管理员查看而移交。

登录页进入的管理模式在应用内播放录像，避免退出管理页后遗留独立播放器；播放依赖 Windows 媒体解码支持。若 MKV 无法解码，提示改由 Windows 管理员在下面的桌面模式中打开。该模式不提供系统文件保存对话框，CSV 导出仍在桌面管理模式使用。

### Windows 管理员桌面入口

从打印认证页面的管理员维护入口或 Windows 安全界面切换到独立管理员账户。打开解压包目录中的 PowerShell：

```powershell
# 已部署工作站
.\scripts\Start-Admin.ps1

# 尚未替换旧程序，先使用新解压包查看本机已有记录
.\scripts\Start-Admin.ps1 -AppPath .\app\PrintGate.exe
```

确认 Windows UAC 后进入页面。第二种方式需确保 `app/appsettings.json` 的 RecordingsDirectory 与已部署配置一致。管理模式不要求安装 Bambu Studio 或 FFmpeg。直接运行 PrintGate.exe 会进入打印认证模式，查看记录需带 `--admin` 参数并提权。普通账户未提权不能打开管理模式。

旧版部署脚本不支持覆盖安装；仅更新查看页面时可先使用第二种方式，避免覆盖正在运行的程序或删除数据库。

## 页面功能

- 默认查询全部历史。姓名、学号、组织、电脑编号支持包含搜索；输入一个日期和 HH:mm:ss 时刻，按本地时间匹配所在使用区间；清空日期可查询全部历史。点击查询应用筛选，刷新维持已应用条件。
- 使用次数、按学号去重人数、未结束数、异常数均对应当前筛选结果。记录每页 20 条；可选每 15 秒刷新。
- “录屏关联”筛选曾有 recording_started 事件的会话；并不保证录像尚未被清理。
- “未结束”仅指没有结束时间，不能判断当前在线；可能正在使用或异常退出尚未恢复。
- “异常记录”包含已结束且非正常关闭、鼠标超时、管理员维护、Windows 锁定原因的会话。
- 点击“记录 / 录像”或双击行，查看姓名、学号、组织、电脑、起止时间、时长、结束原因、最近 500 条会话事件和关联录像。
- 选中已结束且存在的录像后，点击“播放选中录像”或双击打开；桌面管理模式使用 Windows 默认播放器，校园管理员入口使用内置播放器；需播放器支持 MKV。已清理、未结束或无权限的文件会显示提示。录像受 7 天保留和磁盘空间清理策略约束，使用日志不随录像一起删除。
- 左侧系统事件显示已应用查询时刻所在秒的最近 500 条事件，未选日期时显示全部时间的最近 500 条；不应用姓名或组织筛选。
- 导出 CSV 包含当前筛选的全部记录，不只当前页。文件为 UTF-8 BOM，包含公式注入防护。用 Excel 导入时将“学号”列设为文本，避免前导零丢失或长学号转科学计数法。

管理页面只读数据库和录像元数据，不结束会话、不恢复中断、不清理录像，也不修改记录。可以在工作站运行时查看。详情为打开时的快照，重新打开可读取最新记录。

记录描述软件使用会话，不包含实际打印成功率、耗材、模型或打印机当前状态。异常恢复记录的结束时间是恢复时间，不能当作精确退出时间。组织来自用户自行填写。

## 人员频次与精确时间查询

点击左侧“使用人员”切换至人员列表，按学号汇总当前筛选范围内的使用次数，并显示最近使用时间。每页 20 人，可翻页查看所有人员。点击“筛选记录”或“全部历史”，在当前工作台查看该人员的记录和录像；点击“清除人员限定”回到全部人员。组织仍在每条会话中显示，避免将人员不同会话填写的组织错误合并。

左侧侧栏包含“操作记录”“使用人员”和“系统事件”，在同一窗口切换并显示当前选中项。

输入一个日期和具体时间（例如 2026-09-07 14:30:00），点击“查询记录”（也可按回车），在当前列表显示满足“开始时间 ≤ 查询时刻 ≤ 结束时间”的记录，列表同时显示开始及结束时间。输入框精确到秒，按输入时刻本身匹配，不扩展为一整秒。未结束的会话作为待确认候选显示，不能据此认定该时刻确实有人操作。恢复后的异常记录结束时间为恢复时间，同样需要结合录像核实。

从查询结果或人员历史中点击“详情”，在“关联录像”里选择已保存的视频并点击“打开选中录像”。播放前会再次检查文件是否还存在。记录仍保留但视频已过期或因磁盘空间不足被删除时，会显示未找到录像。

## Windows 验收

1. 标准账户直接 `--admin` 被拒绝，独立管理员经 UAC 可打开。
2. 有一条正在使用的会话时打开管理页，确认其结束时间仍为空、Studio 不受影响。
3. 测试姓名/组织/日期、分页、CSV 所有筛选结果、中文和前导零学号导入。
4. 关闭会话后确认详情事件和录像；清理旧录像后再次点击打开应提示缺失。
5. 无数据库、无录像、旧版无组织数据、数据库被占用时，页面应显示可理解的空状态或失败提示。
6. 在实际显示器分辨率和缩放下检查圆角表格、滚动、窗口缩放及播放器调用。

macOS 已交叉编译和运行核心测试，WPF 管理窗口及 UAC 仍需 Windows 实机验收。

## 工作台布局与操作

- 顶部显示当前页面及刷新操作，桌面管理员的记录页提供导出按钮。
- 查询区只保留人员关键词、一个可选时刻、查询与清除；时间格式错误在输入区内显示。
- 查询结果直接显示在当前表格，不额外打开重复的管理窗口；底部显示已应用的时间、数量和分页。
- 记录将姓名与学号、组织与电脑、开始与结束时间分组显示；长组织名可悬停查看全文。
- 清除会移除时间、关键词和人员限定。切换侧栏保持已应用的关键词和时刻，清除个人限定和记录状态分类。
- 自动刷新只刷新已应用条件，详情窗口打开时暂停刷新。缺失或未结束录像不可播放。
