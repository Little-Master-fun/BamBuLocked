# 自定义本地管理员账号

本地管理员独立于校园认证及 Windows 账号。当前支持一组自定义用户名和密码，没有默认账号；校园管理员学号名单仍保留。

## 首次配置

在独立的 Windows 管理员账户下，从新版完整包目录运行：

```powershell
.\scripts\Set-LocalAdministrator.ps1 -AppPath .\app\PrintGate.exe
```

确认 UAC 后，在设置窗口输入用户名、新密码、确认密码，点击保存。用户名 3–64 个字符，不含空格或控制字符；密码至少 10 个字符。用户名不区分大小写，密码区分大小写且不裁剪空格。

首次部署时，在设置完成后运行 Install-Workstation，账号文件会随 app 一起复制并受到安装目录权限保护。

## 已安装旧版的工作站

新功能需要新版 PrintGate.exe / PrintGate.dll 等完整程序文件。不能只把设置脚本放到旧版旁边运行。

1. 完全注销 Genius（或实际专用打印账户），登录独立的 Windows 管理员账户。
2. 将原 `C:\Program Files\PrintGate` 整个目录复制到一个备份目录，保留原配置。
3. 将新版包 `app` 目录内的程序文件复制到原安装目录并覆盖；**保留原 appsettings.json、local-admin.json（如果已有）和 Tools 目录**，不要用空白配置覆盖原设置。不要删除 ProgramData 中的部署备份、使用数据库和录像。
4. 从新版包目录运行下列命令，默认设置已安装程序的本地管理员：

```powershell
.\scripts\Set-LocalAdministrator.ps1
```

5. 保存后重新登录专用 Windows 账户。

此步骤只更新程序及本地管理员配置，不修改 Windows 启动策略。此前出现的“程序未运行”问题还需要继续根据启动日志排查，不能视为本功能已修复。

## 登录与修改

在认证页勾选“本地管理员登录”，输入设置的用户名和密码，组织无需填写。成功后进入管理页；关闭或鼠标超时仍回到认证页，并恢复为校园登录模式。

本地管理员登录不访问校园认证接口。勾选本地模式后，用户名拼错、密码错误或未配置账号均在本机拒绝，不会转发到校园接口。即使忘记勾选，输入与已配置本地管理员完全匹配的用户名也会优先进行本地验证。建议使用与校园账号不同的用户名；该用户名会保留给本地登录。

设置窗口也用于修改用户名、修改密码或忘记密码后的重设，仅允许提权后的 Windows 管理员打开。保存后重新登录专用 Windows 账户生效。密码不会出现在命令行或日志中。

配置保存在安装目录的 `local-admin.json`，仅保存用户名、随机盐、PBKDF2-SHA256 的参数及哈希（600,000 次迭代）。安装目录必须继续只允许 Windows 管理员和 SYSTEM 修改。不要将配置文件提交到公开仓库或分享包中。

连续失败 5 次后，本地登录会暂停 30 秒；此计数仅在当前程序进程内有效。校园管理员名单和 Windows 桌面管理入口不受本地密码修改影响。

## 验证范围

自动测试覆盖加盐哈希、密码错误、用户名匹配、本地凭据不访问校园接口、校园用户原流程、空配置拒绝、失败限流和无效配置。Windows 设置窗口、UAC、文件权限及真实工作站登录仍需实机验证。
